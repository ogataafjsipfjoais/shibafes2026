# 飛翔録 来場者記録受付（GAS）

公開名は任意です。空欄・空白のみの場合は「名もなき挑戦者」で保存・確認・掲載します。飛距離と掲載同意は必須です。

Code.gs に表示HTMLを同梱しています。Index.html は編集用です。変更時は visitorPage_ の文字列も更新し、既存デプロイを新バージョンへ更新してください。アクセス権限は変更しません。

スクリプトプロパティに設定する INBOX_ID と OWNER_EMAIL は公開リポジトリへ書かないでください。来場者の送信は非共有のスタッフ確認ファイルへ保存され、承認操作後のみ公開スプレッドシートへ反映されます。自動承認は行いません。

node gas/visitor-record/test-gas.cjs で入力・匿名名・承認・撤回・精度保持を検証できます。
