# クラウドファンディング返礼品一覧

人力飛行機のクラウドファンディング返礼品10コースの内容、金額、提供予定を紹介するページ。

- 公開URL: https://ogataafjsipfjoais.github.io/shibafes2026/crowdfunding/rewards/
- 正式な支援先: https://camp-fire.jp/projects/990337/view
- 実装: `crowdfunding/rewards/index.html`（HTML・CSS・JavaScriptを1ファイルに集約）
- デプロイ: `.github/workflows/pages.yml`、`tools/build-release.py`、`tools/verify-release.py`

## 方針とデザイン判断（2026-11-09）

以前のデザインは、Amazon型の検索バー、カテゴリ帯、左サイドバー、均一な3列商品カードが強すぎたため廃止。

写真と文字を重視した独自のレイアウトを採用しつつ、返礼品を比較できるページにしました。

1. ヒーロー「クラウドファンディング返礼品一覧」：製作写真と翼の模式図。装飾の模式図は実際の設計図ではありません。
2. 導入「返礼品は全10種類」：製作写真とプロジェクトの背景。
3. 3つのカテゴリ「メッセージ・カード」「オリジナルグッズ」「試験見学会」：カテゴリ絞り込みに直結。
4. 10の返礼品：書籍や展示図録のような非均一レイアウト。余白、写真、文章と価格を優先。
5. 最後の支援案内：申込と決済はCAMPFIREで。

無意味なモーション、過剰なカード装飾、架空のレビュー・割引・カート表現は採用しません。

## 機能

- 10種類の返礼品、金額、仕様、提供予定（確定情報はCAMPFIRE参照）
- 展示からのカテゴリ絞り込み、検索、価格帯絞り込み、並べ替え
- 商品詳細、最大3件の比較、端末内お気に入り保存
- キーボード操作、モバイルレイアウト、省モーション
- レスポンシブデザインとGitHub Pagesでの静的配信

## 検証上の留意点

- 製品モックは「DESIGN IMAGE」と記載。完成品の実物画像とは限りません。
- 商品の在庫、受付状況、条件は公式CAMPFIREページを必ず確認してください。
- GitHub Actionsの公開時は、サイト全体の回帰試験も実行します。
- バナー写真はリポジトリ内の `assets/crowdfunding/` にあるローカル素材を使用しています。
- ほかのページに変更が同時発生した場合はActionsがキャンセルされることがあるため、最新成功したワークフローと公開ページを確認してください。
