# クラウドファンディング返礼品ページ 制作準備

公開予定パス: `/shibafes2026/crowdfunding/rewards/`

このフォルダーは返礼品紹介ページの準備用です。まだ `index.html` を作成していないため、GitHub Pagesには公開されません。

## 公開前に確認すること
- 正式な返礼品名、写真、支援金額、数量、申込条件、配送・実施予定日
- 提供条件の制限事項（数量限定、送料、海外への発送可否など）
- CAMPFIREの確定済みプロジェクトURLと掲載内容の一致
- 写真の掲載許可と出典、未確定情報の非掲載
- PC/スマホ表示、代替テキスト、リンクチェック

## ページ構成案
1. 導入：支援が形になる返礼品
2. 品目一覧：写真＋名称＋確定した金額
3. 各返礼品の背景と製作過程
4. 対応するCAMPFIREの支援プランへ
5. 申込条件・配送と注意事項

確定情報を受け取り次第、このディレクトリに `index.html` を追加し、メインページの「返礼品」ナビゲーションをページリンクへ変更します。
