# 二人乗り人力飛行機クラウドファンディング｜返礼品ページ

- 公開URL: https://ogataafjsipfjoais.github.io/shibafes2026/crowdfunding/rewards/
- 正式な支援先: https://camp-fire.jp/projects/990337/view
- 実装ファイル: `crowdfunding/rewards/index.html`
- GitHub Pages: `.github/workflows/pages.yml` と既存の静的ビルドフロー

## 目的

返礼品のEC的な価格比較より、二人乗り人力飛行機を支援する理由を最初に伝える。

### 情報源

- 2026年機 S-320 Element の飛行記録：180.67m。チーム公式の2026年9月4日の活動報告を参照。
- 2026年のクラウドファンディング目標：41万円。CAMPFIREの募集ページに公表。
- 翼の材料費：約29万円、プラットフォーム手数料：約7.7万円、返礼品製作と送料：約4万円。CAMPFIREに掲載の概算。
- 「今年の目標は妥協しないことです」の引用はCAMPFIRE掲載の本人たちの文章に限る。
- 支援額ごとの具体的な購入部品・エピソード・架空の部員発言は創作しない。

## 情報設計

1. 実際の部員が写る写真と2026年の大会記録。
2. 二人乗り機にこだわる理由と、作業写真・実際の活動報告へのリンク。
3. 支援金を何に使うか。目標額と公開された概算内訳を提示。
4. 返礼品10コースを、3種類に分けてひとつずつ紹介。
5. 最後にCAMPFIREへの明確な案内。

前版のECらしい価格順並べ替え、検索、商品の比較、ハート保存、架空のレビューやカートは廃止。返礼品の金額は「販売価格」ではなく「支援金額」と表記。

## デザイン

- 現場の写真で活動の人間らしさを見せる。
- 日本語主体の見出し。根拠のない比喩・雰囲気だけの英語コピーを使わない。
- 制作現場と返礼品イメージを混同しない。
- 返礼品モックはあくまでデザインイメージであることを各商品と末尾に明示。
- スマートフォンでは支援導線を最下部に固定し、読みやすい1列で表示。
- CSSのみでレイアウト。JavaScriptなしで情報とリンクが読めるようにする。
- 実際の支援状況、残数、条件は常にCAMPFIREの情報が優先する。
