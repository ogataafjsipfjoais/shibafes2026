# TeamBirdmanTrial クラウドファンディング返礼品紹介ページ 制作準備

公開予定パス: `/shibafes2026/crowdfunding/rewards/`

CAMPFIREで返礼品は公開済みです。現在制作中なのは独立した返礼品紹介ページです。まだ `index.html` を作成していないため、このディレクトリに専用ページは公開されていません。

現在の返礼品への公式リンク： https://camp-fire.jp/projects/990337/view

## 公開前に確認すること
- CAMPFIREで公開済みの正式な返礼品名、写真、支援金額、数量、申込条件、配送・実施予定日
- 提供条件の制限事項（数量限定、送料、海外への発送可否など）
- CAMPFIREの確定済みプロジェクトURLと掲載内容の一致
- 写真の掲載許可と出典、未確定情報の非掲載
- PC/スマホ表示、代替テキスト、リンクチェック

## ページ構成案
1. 導入：支援が形になる返礼品
2. 品目一覧：写真＋名称＋確定した金額
3. 各返礼品の背景と製作過程
4. 対応するCAMPFIREの支援プランへ
5. 申込条件・配送と注意事項

公開済みのCAMPFIRE返礼品情報を正確に整理できた時点で、このディレクトリに `index.html` を追加します。その時点でメインページの「返礼品」導線も専用ページへ更新します。
