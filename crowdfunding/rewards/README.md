# FLIGHT COLLECTION｜返礼品の格納庫

Team Birdman Trial クラウドファンディングの返礼品紹介・比較サイトです。

- 公開URL: https://ogataafjsipfjoais.github.io/shibafes2026/crowdfunding/rewards/
- 公式支援先: https://camp-fire.jp/projects/990337/view
- エントリーポイント: `crowdfunding/rewards/index.html`（CSSとJavaScriptを内包した静的HTML）
- GitHub Pages: リポジトリ共通の `.github/workflows/pages.yml` で自動公開

## コンセプト

Amazon型の「商品が探しやすい」情報設計は維持しつつ、組織名を前面に出さず、人力飛行機の格納庫を主題に独自のデザインとしました。
S-320の翼幅40mをヒーローで示し、翼の装飾的な模式図、図面風の線・数値、格納庫管理票のような商品番号を使用します。模式図は実際の設計図ではありません。

## 利用者ができること

- 全10種類の返礼品を検索・絞り込み・並べ替え
- グリッド／リスト表示切り替え
- 商品詳細を開く
- お気に入りをブラウザ内に保存
- 最大3種類の返礼品を比較
- CAMPFIREの正式な支援ページに移動

カート・決済・利用者レビューは実装していません。支援額、受付状況、返礼品の提供条件、残数はCAMPFIREを正とします。

## デザイン判断

- 色: 深緑とオフホワイトを基調に、操作や誘導でオレンジを使用
- 文字: 日本語の力強い見出しと、寸法・管理番号に等幅フォント
- 写真: 既存の人力飛行機関連画像を使用。返礼品の仮画像は「DESIGN IMAGE」と明示
- 動き: 商品にマウスを載せるなど操作に応じた最小限の動き。省モーション設定を尊重
- モバイル: 2列商品グリッド、絞り込みの開閉、固定の支援導線
- アクセシビリティ: 見出し階層、画像説明、キーボード操作と明示的なフォーカスを用意

## 更新時の確認

1. CAMPFIREと金額・仕様・提供予定日を照合する
2. HTMLの構文、検索・比較・お気に入りをPCとスマホで確認
3. `tools/build-release.py` および `tools/verify-release.py` による全体デプロイの回帰試験
4. GitHub PagesのActionsが成功し公開URLで表示できることを確認
