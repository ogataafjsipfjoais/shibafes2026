# S-330「鵠」クラウドファンディング：制作記録型LP

## 新しいデザイン方針（2026年11月10日）
一般的な企業LP（写真+文章の繰り返し、均等なカード、見出しとCTA）から脱却し、
**機体をつくる学生の「製作資料」と「公開された活動記録」を読み進めるようなサイト**に再設計。

### 見せ方
- 表紙: S-330の巨大な番号・機体名「鵠」・2026年の実際の作業写真。写真はS-330完成機ではないと明示。
- 翼の模式線画: 装飾としての概念図。実際のS-330の設計図ではないと併記。S-320の旧3D展示の流用を回避。
- 2017→2026→2027: 先代S-230 CygnusからS-320 Element、S-330への継承を年表として表示。
- 製作写真: 運搬・整備・大会準備の実写と180.67mの飛行記録を見せる。
- 二人のパイロット: 二人で一機を飛ばすことが分かる一対の組版。
- 資金計画: 目標41万円、翼材料費約29万円などを製作管理票のように示す。商品的な価格比較表にはしない。
- 返礼品: 10コースを3カテゴリに整理。ECのカードグリッドは不採用。

### デザインシステム
- 濃い緑 #162f29、生成り #e9e5d9、朱色 #af482d。無意味なグラデーションは禁止。
- Noto Serif JP / Noto Sans JP / DM Sans を役割で使い分ける。
- 角丸・影付きカードや装飾的なガラスUIを用いない。紙と印刷物の罫線・余白・番号で統一。
- PCは最大1280pxで2カラムの表紙、スマホは1カラムへ切り替え。
- スクロールジャックや旧機の3Dモデルは使わない。静的HTMLで即座に内容が読める。
- 明確な支援CTAはファーストビュー、資金欄、ページ末尾に設置する。
- PC/スマホで横スクロール禁止、最初の画面に支援CTA、写真読込、アクセシビリティを実ブラウザで検証。

### 検討した別案
1. 3D飛行体験をさらに強化 → 既存の学祭演出と同じになるため不採用。
2. 写真中心の企業LP → 一般的で団体固有の技術・記録が伝わらず不採用。
3. 製作日誌・記録紙型のエディトリアル → 技術への挑戦、現場感、資料の実在性、情報の分かりやすさを両立できるため採用。

実際に独立したAI同士で討論したわけではなく、デザイン・実装・検証の観点で比較して採用。
