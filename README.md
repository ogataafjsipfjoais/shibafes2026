# TBT 芝浦祭2026 特設サイト

既存サイトと共通のヘッダー・フッターを使用する、芝浦祭2026特設サイトです。

## ローカル確認

URLの `/shibafes2026/` を維持するため、親ディレクトリで起動してください。

```sh
php -S 127.0.0.1:8765 -t .
```

http://127.0.0.1:8765/shibafes2026/ を開きます。

## 物販ページの更新

商品情報は `content/goods-catalog.json`、演出は `assets/goods-hangar.js` と `assets/goods-hangar.css` で管理しています。

```sh
python3 tools/build-goods-hangar.py
```

生成されたHTMLとバージョン付きアセットもコミットしてください。詳細は `GOODS-README.md` を参照してください。

## 運用

ランキングは公開用シートから直接取得します。入力は既存スプレッドシートの「ランキング」タブで行い、「ランキング公開（自動）」は編集しないでください。反映にActionsの手動実行は不要です。詳細は `DEPLOYMENT.md` を参照してください。
認証情報・秘密鍵・個人情報をリポジトリに追加しないでください。
